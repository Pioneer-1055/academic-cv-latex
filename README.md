# academic-cv-latex
# Academic CV Templates

LaTeX templates for academic applications, optimized for robotics/space science PhD programs.

## 📁 Available Templates

| Template | Purpose | Preview |
|----------|---------|---------|
| `cv_hkust.tex` | HKUST PhD application | [PDF](cv_hkust.pdf) |
| `cv_general.tex` | General academic CV | [PDF](cv_general.pdf) |
| `rp_framework.tex` | Research proposal framework | [PDF](rp_framework.pdf) |

## 🎨 Features

- **XeLaTeX support**: Chinese/English bilingual
- **ORCID integration**: Automatic link generation
- **Google Scholar**: Citation count display
- **GitHub stats**: Repository contribution graph
- **Customizable colors**: University-themed (HKUST Blue, etc.)

## 🚀 Usage

```bash
# Compile with XeLaTeX
xelatex cv_hkust.tex
